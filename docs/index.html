LA TEVA CAIXA D’EINES

Un formulari per orientar-te.

Vectors i derivades

Δr = r₂ − r₁
v̄ = Δr / Δt
v = dr/dt
a = dv/dt
|r| = √(x² + y² + z²)

Distància: camí recorregut. Desplaçament: vector entre els extrems.

MRU i MRUA

x = x₀ + vt (MRU)
v = v₀ + at
x = x₀ + v₀t + ½at²
v² = v₀² + 2a(x − x₀)

En vertical, si +y és cap amunt, a = −g. Respecta la g de l’enunciat.

Tir parabòlic

vx = v₀ cosθ
vy = v₀ sinθ − gt
x = x₀ + v₀ cosθ · t
y = y₀ + v₀ sinθ · t − ½gt²

Si surt i arriba a la mateixa altura: T = 2v₀sinθ/g i R = v₀²sin(2θ)/g.

Moviment circular

ω = 2πf   ·   T = 1/f
v = ωR   ·   aₙ = v²/R = ω²R
ω = ω₀ + αt
Δθ = ω₀t + ½αt²
aₜ = αR

1 volta = 2π rad · rpm ÷ 60 = Hz. Les equacions amb α constant són d’MCUA.

Conversions i gràfiques

km/h ÷ 3,6 = m/s
cm ÷ 100 = m
Pendent de x–t → velocitat
Pendent de v–t → acceleració
Àrea amb signe sota v–t → Δx

La distància s’obté sumant les àrees en valor absolut.

Derivades bàsiques

d(c)/dt = 0
d(t)/dt = 1
d(t²)/dt = 2t
d(t³)/dt = 3t²

Deriva cada component del vector per separat. No derivis els vectors unitaris constants.

Aprèn al teu ritme.

La preparació de l’examen afegeix 11 problemes A–K i 6 exercicis vectorials V1–V6. El mode examen oculta les ajudes fins al lliurament i guarda l’intent en aquest navegador. Les justificacions i els dibuixos són d’autorevisió. El dossier conté els 73 exercicis de les fotos, amb enunciats adaptats. Algunes tasques simbòliques es treballen introduint coeficients; les expressions completes són a la resolució. Les explicacions obertes i els dibuixos són per a l’autorevisió.

  1. Tria un exercici i prepara dades, esquema i equacions.
  2. Introdueix cada resposta en la unitat indicada. Pots escriure decimals amb coma o punt, fraccions, pi i sqrt(2).
  3. Comprova els resultats. Si et cal ajuda, obre les pistes d’una en una.
  4. Consulta la resolució i compara-la amb el teu procediment.

La correcció admet un marge d’arrodoniment de l’1% (mínim 0,005 en la unitat indicada). Les preguntes conceptuals tenen correcció exacta.

«Resolt» vol dir totes les respostes correctes sense obrir la resolució; pot ser amb pistes. Si has obert la resolució, queda com a «Consultat». Les notes no es corregeixen automàticament.

El progrés i les notes es guarden només en aquest navegador. No se sincronitzen entre dispositius i es poden perdre si esborres les dades del navegador. Pots exportar-ne una còpia a «El meu progrés».
